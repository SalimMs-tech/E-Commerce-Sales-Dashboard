# E-Commerce Sales Dashboard

#Project Overview
This project is an interactive Excel dashboard built to analyze e-commerce sales data and provide business insights through data visualization.

The dashboard helps track:
- Product sales performance
- Regional profitability
- Customer purchasing behavior
- Category performance
- Sales trends
The project was created using Microsoft Excel with Pivot Tables, Pivot Charts, Slicers, and dashboard design techniques.
--

- Data Cleaning and Preparation

- Profit and Sales Analysis
